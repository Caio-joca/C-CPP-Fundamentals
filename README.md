# C and C++ Fundamentals

Uma seleção de exercícios autorais desenvolvidos durante meus estudos iniciais de programação em C e C++.

## Exercícios

- `matrix-min-max`: geração de matriz e busca do menor e maior valor usando ponteiros.
- `number-base-converter`: conversão entre representações decimal, hexadecimal e octal.
- `pointer-basics`: exemplo introdutório de declaração e desreferenciamento de ponteiros.
- `array-addresses`: navegação por vetores e inspeção de valores e endereços.

Os exercícios foram preservados como registro da evolução no aprendizado. Projetos incompletos, builds, arquivos de IDE e exemplos já publicados em outros repositórios foram excluídos.
